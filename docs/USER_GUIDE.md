# 订阅镜使用指南

## 1. 安装

从 GitHub Releases 下载 `SubscriptionLens-v1.1.0-windows-x64-setup.exe`，双击完成安装。默认按当前 Windows 用户安装，不需要管理员权限。

安装后可以从开始菜单运行“订阅镜”。程序自己的 WebView 数据位于应用安装目录下的 `subscription-lens-data`。需要移除时，从 Windows“设置 → 应用 → 已安装的应用”正常卸载。

## 2. 准备完整凭证

### 推荐：Session JSON

1. 使用常用浏览器登录自己的 ChatGPT。
2. 在同一个浏览器配置文件中打开 `https://chatgpt.com/api/auth/session`。
3. 复制页面显示的完整 JSON，不要只复制其中一小段。
4. 粘贴到订阅镜，等待本地完整性检查。

完整 Session JSON 至少需要提供可解析的 Access Token，并能取得以下信息：

- 有效邮箱；
- 用户 ID；
- ChatGPT 账户 ID；
- 未过期的令牌有效期。

缺少任一必需项时，查询按钮不会启用。

### 其他格式

- Codex `auth.json`：需要完整 JSON，不能只复制 `access_token` 的一部分。
- Access Token：只有令牌声明本身包含身份、账户范围和有效期时才能查询。
- Session Token：本地先检查长度与危险字符，随后只向 `chatgpt.com/api/auth/session` 换取完整会话；会话不完整时不会继续查询订阅数据。

凭证可登录你的账号。不要让他人代取，不要复制到网页查询站，不要发送截图，也不要提交到 GitHub Issue。

## 3. 查询

1. 粘贴凭证并等待四项检查：令牌结构、身份信息、账户范围、有效期限。
2. 勾选账号归属确认。
3. 点击“验证并查询”。
4. 查看各数据源状态。部分数据源失败时，其余成功结果仍会保留。

`Ctrl+Enter` 可以开始查询。成功后输入框自动清空；未点击查询的输入在 5 分钟后自动清空。

## 4. 支付方式显示

- **Visa / Mastercard**：显示 ChatGPT 支付方式端点实际返回的品牌。卡号最多显示前 6 位与尾号 4 位，中间始终隐藏。
- **只有尾号**：部分支付响应只提供 `last4`。此时界面只显示尾号并明确说明前 6 位不可用，不会推测或伪造。
- **Apple App Store**：当前订阅来源为 iOS/Apple 时显示 App Store 标识，不展示账户中可能另存的网页银行卡。
- **Google Play**：当前订阅来源为 Android/Google Play 时显示 Google Play 标识。
- **其他银行卡**：可显示通用银行卡或上游提供的品牌名称；完整卡号永远不会写入查询结果。

支付方式列表代表 ChatGPT 本次返回的已保存方式。若上游没有明确关联到某张历史发票，程序不会声称它就是某一张发票的付款卡。

## 5. 理解结果

- **当前套餐/状态**：优先使用账户权益和当前订阅周期交叉判断。
- **币种/金额**：币种可来自当前订阅；金额优先显示最近一张成功网页账单。移动端金额不猜测。
- **自动续费**：只显示上游明确返回的布尔状态；未返回时显示由商店管理或未知。
- **网页账单**：只包括 `chatgpt.com` 端点实际返回的账单。
- **移动记录**：仅为最近可确认记录，不等于 Apple/Google 完整购买历史。
- **Codex 额度**：显示当前账号可见的滚动窗口；部分 Business/Enterprise 账号不返回个人窗口。
- **数据来源**：“可用”表示本次取得可解析响应；“未取到”表示端点不可用、无权限或格式变化。

## 6. 常见问题

### 凭证看起来能用，但被判定不完整

重新复制整个 Session JSON。不要只复制 `accessToken` 的开头或结尾，也不要删除 `user`、`account` 等对象。结构完整不等于服务端有效；服务端仍会拒绝过期、撤销或不属于该账户的令牌。

### 显示 401 或凭证过期

重新登录 ChatGPT，再获取新的 Session JSON。不要反复重试旧凭证。

### 为什么没有银行卡前 6 位

多数支付接口出于安全原因只返回卡组织和尾号 4 位。订阅镜只显示上游明确返回的数据，不会使用 BIN 数据库反推或伪造前 6 位。

### 当前订阅能看到，但没有网页账单

移动商店订阅、免费账号、地区差异或端点变化都可能导致网页账单为空。到原购买平台查看完整收据。

### 为什么不提供取消续费按钮

本项目坚持只读。订阅管理应在原购买平台进行，以避免错误操作和扩大凭证权限风险。

### 如何卸载

退出程序，在 Windows“设置 → 应用 → 已安装的应用”中找到“订阅镜”并卸载。应用不安装系统服务，也不创建云端数据。
