# 订阅镜使用指南

## 1. 运行前

把绿色版压缩包完整解压到一个可写目录，例如 `D:\Apps\SubscriptionLens`。不要放在需要管理员权限写入的目录，也不要直接从压缩软件预览窗口运行。

程序启动后只会在同目录创建 `subscription-lens-data`。不需要安装、注册服务或设置开机启动。

## 2. 准备凭证

### 推荐：Session JSON

1. 使用常用浏览器登录自己的 ChatGPT。
2. 在同一个浏览器配置文件中打开 `https://chatgpt.com/api/auth/session`。
3. 如果页面显示包含 `accessToken` 的 JSON，复制整页文本。

### 其他支持格式

- 单独的 JWT Access Token（通常以 `eyJ` 开头并有三个点分段）。
- Codex `auth.json` 的完整 JSON。
- ChatGPT session token。程序会直接向 `chatgpt.com/api/auth/session` 交换 Access Token。

凭证可登录你的账号。不要让他人代取，不要复制到网页查询站，不要发送截图。

## 3. 查询

1. 粘贴凭证。
2. 勾选“我只查询自己拥有或获明确授权访问的账号”。
3. 点击“开始本地核对”。
4. 查看各数据源状态。部分数据源失败时，其余成功结果仍会保留。

`Ctrl+Enter` 可以开始查询。成功后输入框自动清空；未点击查询的输入在 5 分钟后自动清空。

## 4. 理解结果

- **当前套餐/状态**：优先使用账户权益和当前订阅周期交叉判断。
- **币种/金额**：币种可来自当前订阅；金额优先显示最近一张成功网页账单。移动端金额不猜测。
- **自动续费**：只显示上游明确返回的布尔状态；未返回时会显示由商店管理或未知。
- **网页账单**：只包括 `chatgpt.com` 端点实际返回的账单。
- **移动记录**：仅为最近可确认记录，不等于 Apple/Google 完整购买历史。
- **Codex 额度**：显示当前账号可见的滚动窗口；部分 Business/Enterprise 账号不返回个人窗口。
- **数据来源**：绿色表示本次取得了可解析响应；灰色表示端点不可用、无权限或格式变化。

## 5. 常见问题

### 显示 401 或凭证过期

重新登录 ChatGPT，再获取新的 Session JSON。不要反复重试旧凭证。

### 当前订阅能看到，但没有网页账单

移动商店订阅、免费账号、地区差异或端点变化都可能导致网页账单为空。到原购买平台查看完整收据。

### 为什么不提供取消续费按钮

本项目坚持只读。订阅管理应在原购买平台进行，以避免错误操作和扩大凭证权限风险。

### 如何彻底卸载

退出程序并删除整个解压目录。程序没有安装服务，也不创建自己的云端数据。
