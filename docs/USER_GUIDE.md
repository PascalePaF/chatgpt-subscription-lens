# 订阅镜使用指南

## 1. 安装

从 GitHub Releases 下载 `SubscriptionLens-v1.1.2-windows-x64-setup.exe`，双击完成安装。默认按当前 Windows 用户安装，不需要管理员权限。

安装后从开始菜单运行“订阅镜”。它是固定 1280 × 800 的原生桌面窗口，不会打开浏览器，也不需要 WebView2。需要移除时，从 Windows“设置 → 应用 → 已安装的应用”正常卸载。

## 2. 准备完整凭证

### 推荐：Session JSON

1. 使用常用浏览器登录自己的 ChatGPT。
2. 在同一个浏览器配置文件中打开 `https://chatgpt.com/api/auth/session`。
3. 复制页面显示的完整 JSON，不要只复制其中一小段。
4. 粘贴到订阅镜的三行输入框，等待本地完整性检查。

完整 Session JSON 至少需要提供可解析的 Access Token，并能取得有效邮箱、用户 ID、ChatGPT 账户 ID和未过期的令牌有效期。缺少任一必需项时，程序不会进入订阅查询。

### 其他格式

- Codex `auth.json`：需要完整 JSON，不能只复制 `access_token` 的一部分。
- Access Token：只有令牌声明本身包含身份、账户范围和有效期时才能查询。
- Session Token：本地先检查长度与危险字符，随后只向 `chatgpt.com/api/auth/session` 换取完整会话；服务端返回仍不完整时不会继续。

凭证可登录你的账号。不要让他人代取，不要复制到网页查询站，不要发送截图，也不要提交到 GitHub Issue。

## 3. 查询

1. 粘贴凭证。输入区固定显示三行，不会把整份长 JSON 铺满窗口。
2. 查看完整性结论。
3. 勾选账号归属确认。
4. 点击“开始只读查询”。

成功后输入立即清空；没有开始查询的输入会在闲置 5 分钟后自动清空。网络查询在后台进行，窗口不会冻结。

## 4. 阅读卡片正面

- **左侧**：当前套餐、是否生效、剩余时间、到期时间和自动续费。
- **右侧黑色支付卡**：支付渠道、脱敏卡号或商店管理状态、有效期/金额，以及对应 3D 图标。
- **Pro 20X**：黑金。
- **Pro 5X**：蓝色。
- **Plus**：绿色。
- **Free**：灰色。

## 5. 阅读卡片背面

背面左侧固定保留五个额度槽位：Codex、Chat、网页端 Pro、生图、Deep Research。程序只显示本次响应中能够明确识别的额度；没有返回或无法可靠分类的字段会显示“未返回”，不会按套餐名称猜测。

背面右侧最多显示最近 4 条可确认账单。网页账单只包括 `chatgpt.com` 返回的记录；移动记录只是 ChatGPT 账户端点最后确认的订阅，不等于 Apple/Google 完整购买历史。

## 6. 支付方式规则

- **Visa / Mastercard**：显示实际返回的卡组织。卡号最多显示前 6 位与尾号 4 位，中间始终隐藏。
- **只有尾号**：如果上游只提供 `last4`，界面只显示尾号，不推测前 6 位。
- **Apple App Store**：订阅来源为 iOS/Apple 时优先显示 App Store 图标，不拿账户中的网页银行卡冒充移动付款方式。
- **Google Play**：订阅来源为 Android/Google Play 时显示 Google Play 图标。
- **未知渠道**：显示“支付信息未返回”，不做猜测。

## 7. 常见问题

### 凭证看起来能用，但被判定不完整

重新复制整个 Session JSON。不要删除 `user`、`account` 等对象，也不要只复制 Token 的开头或结尾。结构完整不等于服务端有效；服务端仍会拒绝过期、撤销或不属于该账户的令牌。

### 显示 401 或凭证过期

重新登录 ChatGPT，再获取新的 Session JSON。不要反复重试旧凭证。

### 为什么某些额度显示“未返回”

OpenAI 没有面向第三方发布统一的个人 ChatGPT 全额度 API。账号类型、地区和内部端点版本不同，返回字段会变化。程序宁可显示未知，也不会把套餐宣传值当作个人实时余额。

### 为什么没有银行卡前 6 位

多数支付响应出于安全原因只返回卡组织和尾号 4 位。订阅镜只显示明确返回的数据，不使用 BIN 数据库反推或伪造前 6 位。

### 当前订阅能看到，但没有网页账单

移动商店订阅、免费账号、地区差异或端点变化都可能导致网页账单为空。到原购买平台查看完整收据。

### 为什么不提供取消续费按钮

本项目坚持只读。订阅管理应在原购买平台进行，以避免错误操作和扩大凭证权限风险。

### 如何卸载

退出程序，在 Windows“设置 → 应用 → 已安装的应用”中找到“订阅镜”并卸载。应用不安装系统服务，也不创建云端数据。
